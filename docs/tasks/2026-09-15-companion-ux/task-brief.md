## Goal

Make the companion quiet when unused and easy to resume without losing cards or conversations.

## Success Criteria

- Retain 20 cards with answers, drafts and conversations; support previous/history and a pending automatic card.
- Continue chat after dismissal and card navigation; provide stop/retry and restore the conversation.
- Default to a 2–4 line summary, bound small-screen height, keep request/completion state visible.
- Simplify menus; add a directory/check/preview knowledge wizard and explicit session/project/global settings scopes.
- Save only the favorite directory when collecting; retain independent preference fields.
- Layer explanations and original sources; add session feedback and an economical generation mode.
- Preserve plain-language explanations, explicit correct answers, source boundaries and main-agent independence.
- Follow-up: structured short lessons with explicit scope, visible examples/diagrams, targeted clarification and compact-window detail hints. Sequential article learning remains a later enhancement.
- Verify controller races, keyboard UI, settings writes, wizard, real pi flow and documentation.

## Scope

Controller, terminal UI, menus, configuration, knowledge onboarding, offline verification and user documentation.

## Constraints

History and learning preferences are session-local. Do not change original notes, publish, commit or install globally. Existing saved layouts remain available; no external model calls are needed for validation.
